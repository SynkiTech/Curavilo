   550→# 11. IDOR / BOLA PROTECTION
   551→
   552→Treat every object-ID endpoint as a potential Broken Object Level Authorization vulnerability.
   553→
   554→For every endpoint/action:
   555→
   556→```text id="5e4v4b"
   557→GET /patients/:id
   558→GET /reports/:id
   559→GET /invoices/:id
   560→GET /files/:id
   561→POST /payments/:id/refund
   562→PATCH /staff/:id
   563→DELETE /workflow/:id
   564→```
   565→
   566→verify object authorization server-side.
   567→
   568→Do NOT rely on:
   569→
   570→* hidden UI elements
   571→* UUID unpredictability
   572→* route protection alone
   573→* client-side role checks
   574→
   575→Even if IDs are UUIDs, authorization is still mandatory.
   576→
   577→OWASP specifically identifies Broken Object Level Authorization as the first API Security Top 10 risk.

   896→Passwords must:
   897→

   899→* never be logged
   900→* never be returned through APIs
   901→* never be placed in URLs
